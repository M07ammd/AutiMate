لقد قمت للتو بتحديث ملف `ai_service.dart` في مشروعك وأضفت دالة جديدة اسمها `saveReportToNodeJs`. 

الآن، العمل مقسم إلى جزأين: **الجزء الأول في تطبيق الموبايل (Flutter)**، و**الجزء الثاني في سيرفرك (Node.js)**. إليك ما يجب فعله بالضبط:

### 1. في تطبيق الموبايل (Flutter)
عندما تنتهي اللعبة، ستقوم بإنهاء الجلسة واستلام التقرير من بايثون، ثم تمرره فوراً للسيرفر الخاص بك (Node.js) هكذا:

```dart
void onGameOver() async {
  // 1. احصل على التقرير النهائي من الذكاء الاصطناعي (بايثون)
  final report = await AIService.endSession();
  
  if (report != null) {
    // 2. أرسل التقرير إلى سيرفر Node.js ليتم حفظه في قاعدة البيانات
    String childId = "12345"; // رقم الطفل الحالي
    String gameId = "colors_room"; // اسم أو رقم اللعبة
    
    await AIService.saveReportToNodeJs(report, childId, gameId);
  }
}
```

### 2. في سيرفر الـ Node.js (الخاص بك)
كل ما عليك فعله في سيرفر الـ Node.js هو إنشاء مسار (Route) جديد ليستقبل هذه البيانات ويحفظها في قاعدة البيانات (سواء كانت MongoDB أو MySQL).

**مثال تطبيقي في Node.js (باستخدام Express.js):**
```javascript
const express = require('express');
const app = express();
app.use(express.json()); // لكي يستطيع قراءة الـ JSON

// هذا هو المسار الذي سيستقبل البيانات من Flutter
app.post('/api/reports', async (req, res) => {
    try {
        // البيانات التي أرسلها Flutter ستكون موجودة هنا
        const { child_id, game_id, report_data } = req.body;

        console.log(`استلام تقرير للطفل: ${child_id} في اللعبة: ${game_id}`);
        console.log("نسبة التشتت:", report_data.distraction_percentage);
        
        // --- كود الحفظ في قاعدة البيانات ---
        // مثال إذا كنت تستخدم MongoDB (Mongoose):
        /*
        const newReport = new ReportModel({
            childId: child_id,
            gameId: game_id,
            duration: report_data.duration_seconds,
            distractionScore: report_data.distraction_percentage,
            emotions: report_data.emotion_percentages
        });
        await newReport.save();
        */

        // الرد على الموبايل بنجاح العملية
        res.status(201).json({ message: "تم حفظ التقرير بنجاح في قاعدة البيانات!" });
    } catch (error) {
        console.error(error);
        res.status(500).json({ error: "حدث خطأ أثناء الحفظ" });
    }
});

app.listen(3000, () => console.log('Node.js Server is running on port 3000'));
```

**بهذه الخطوات:**
- سيرفر البايثون مسؤول فقط عن **الذكاء الاصطناعي**.
- سيرفر الـ Node.js مسؤول عن **إدارة البيانات والمستخدمين**.
- تطبيق الموبايل هو **همزة الوصل** بينهما.

هل كل شيء واضح بخصوص هذه الخطوات، أم تريد أن نتعمق في جزء معين منها؟
